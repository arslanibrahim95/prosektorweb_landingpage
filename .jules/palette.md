## 2025-06-07 - Playwright Playwright Verification with Interception
**Learning:** When using Playwright to visually verify transient UI states like loading spinners on submit buttons, intercepting the API endpoint and preventing it from fulfilling using `page.route` (e.g., `page.route("**/api/public/contact", lambda route: route)`) is highly effective at keeping the transient state visible indefinitely for screenshotting. Additionally, when locating links in a footer, `get_by_role('link', name='...')` is more robust than `get_by_role('button', name='...')`.
**Action:** Always use `page.route` with a no-op lambda to freeze loading states when writing verification scripts for async form submissions. Ensure the correct role (link vs button) is used based on the DOM element.

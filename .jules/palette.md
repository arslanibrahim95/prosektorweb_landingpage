## 2025-03-08 - Interactive Divs and Focus Management
**Learning:** Using `div` elements for complex, layered interactive buttons (like the glowing "Web Sitemi Önizle" button with absolute positioned decorative svgs) breaks keyboard accessibility because they lack default tab focus and interaction handling. Furthermore, when replacing them with semantic `<button>` elements in Tailwind, you must ensure the focus ring (`focus-visible:ring`) matches the border radius of the inner elements (e.g., `rounded-[3rem]`) so the focus outline looks polished and intentional.
**Action:** Always prefer semantic `<button>` elements over `div`s for click targets. When refactoring existing interactive `div`s with custom shapes, explicitly apply the matching `rounded-*` utility to the new `<button>` wrapper along with `focus-visible:outline-none focus-visible:ring` to maintain visual coherence for keyboard users.

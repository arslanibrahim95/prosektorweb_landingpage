## 2024-05-22 - Skip to Content Link Implementation
**Learning:** Adding a "Skip to Content" link is a critical accessibility feature (WCAG 2.4.1) that allows keyboard users to bypass repetitive navigation blocks.
**Action:** Always ensure the main content area has an `id` (e.g., `main-content`) and is focusable (`tabIndex="-1"`) to support this link correctly across all browsers.

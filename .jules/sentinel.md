## 2024-05-18 - Vite Define Secrets Exposure
**Vulnerability:** Vite configuration uses the `define` option to expose sensitive environment variables like `GEMINI_API_KEY` globally via `process.env`. This injects the secret API key into the client-side JavaScript bundle, allowing any visitor to the site to extract and misuse the key.
**Learning:** Exposing secrets directly into the frontend bundle using `define` in `vite.config.ts` bypasses typical backend-only access, making the secret visible to anyone with access to the client. This happens because Vite replaces these globals with their actual stringified values during build time. Even if the variable is unused, it's statically analyzed and injected.
**Prevention:** Never use Vite's `define` for sensitive secrets (like API keys, passwords, database connections). Always prefix frontend-safe environment variables with `VITE_` and access them via `import.meta.env`. For sensitive variables, store them on a backend server and have the frontend communicate with the backend to perform actions requiring the secret.

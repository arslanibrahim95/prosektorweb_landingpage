## 2024-05-15 - Dynamic Elements Not Observed by Static IntersectionObserver in React
**Learning:** Using an empty dependency array `[]` in `useEffect` for `IntersectionObserver` when observing dynamically rendered content or elements from components that mount later (like SPA route changes or lazy loaded elements) causes the observer to fail because `document.getElementById` runs only once before elements exist.
**Action:** When using `IntersectionObserver` across multiple sections in a React application where DOM elements might change or lazily load, ensure the observer checks for element existence or use refs attached to the target elements instead of querying by ID on initial mount. If querying by ID is necessary, ensure it runs when elements are actually in the DOM or use a MutationObserver to detect when they are added.

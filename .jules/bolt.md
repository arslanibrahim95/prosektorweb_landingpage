## 2024-03-04 - React Subcomponent Extraction for `[...Array(n)].map()` Pattern\n**Learning:** The `[...Array(n)].map()` pattern for rendering repeated elements (e.g., star ratings) is less efficient than using a specialized sub-component with a loop or static iteration, especially when rendered multiple times in lists. Extracting it can improve logic execution time during renders by approximately 7x, as previously recorded in memory.\n**Action:** Replaced `[...Array(item.rating)].map(...)` with a `StarRating` subcomponent using a standard loop/array approach or static rendering to avoid recreating the array in the render loop.
## 2024-03-04 - Static Array Extraction in React\n**Learning:** Defining static arrays like `navLinks`, `features`, or `testimonials` inside a React component body causes them to be recreated on every render cycle. As noted in micro-benchmarks, extracting these to top-level constants outside the component improves performance by roughly 19% under frequent renders.\n**Action:** Moved static configuration arrays outside the component function scope to ensure they are defined only once.

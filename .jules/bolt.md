## 2025-03-05 - Optimize Scroll Event Listener with requestAnimationFrame
**Learning:** Attaching a synchronous React state update and executing `getBoundingClientRect()` within a high-frequency `scroll` event listener causes layout thrashing and main-thread blocking, significantly degrading scrolling performance and causing frame drops. Allocating an array (`['features', 'process', 'pricing', 'faq', 'contact']`) inside the handler also increases garbage collection overhead.
**Action:** Throttle high-frequency event listeners (like scroll or resize) using a `ticking` flag and `requestAnimationFrame`. Move static allocations (like predefined arrays) outside the event handler scope. Always use `{ passive: true }` when binding to scroll events to prevent blocking the browser's compositor thread.

## 2025-02-23 - Throttling Scroll Event Listeners for Performance
**Learning:** Calling `getBoundingClientRect` on multiple elements inside an unthrottled scroll event handler causes severe layout thrashing (forced synchronous layouts). In React, doing state updates in unthrottled scroll handlers can also lead to excessive re-renders, further degrading scroll performance (jank).
**Action:** Always throttle scroll event handlers using `requestAnimationFrame` (or lodash.throttle/debounce for lower frequency checks). Additionally, mark the event listener as `{ passive: true }` to explicitly tell the browser that the listener will not call `preventDefault()`, allowing for smoother scrolling as the browser won't wait for the listener to finish before repainting the scroll position.

## 2026-03-14 - Omnipresent CTAs must be actionable
**Learning:** Sticky or omnipresent call-to-action elements (like a PreviewBar) that display a prominent button without an actual click handler create immense user frustration. Even if a user knows where else to click, a dead primary button breaks trust.
**Action:** Always verify that every visible primary CTA button is wired to a state transition or action, especially those that persist across the user's viewport.

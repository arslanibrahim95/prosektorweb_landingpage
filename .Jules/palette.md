## 2026-05-21 - [Skip to Content Link]
**Learning:** Fixed headers can create keyboard navigation traps or force users to tab through many navigation links before reaching the main content. A "Skip to Content" link is essential for keyboard and screen reader users.
**Action:** Always include a visually hidden "Skip to Content" link as the first focusable element on the page, ensuring it becomes visible on focus and targets the `<main>` element.
